# Archive

> **NOTICE**: This directory is an archive of deprecated and superseded modules. It is no longer maintained and updated.

## Overview

The code in this directory preserves legacy prototypes and experimental architectures for historical reference only:

* `acmp/`: Legacy component abstraction. Superseded by Atoolkit.
* `aflow/`: Legacy execution graph flow runtime.
* `agraph/`: Legacy graph data structure. Superseded by `Acircuit`.
* `awgl2/`: Legacy WebGL2 component wrappers and utilities.
* `awgpu/`: Legacy WebGPU component system. Superseded by `Awgpu` in `Atoolkit/awgpu`.

None of the modules in this folder receive bug fixes, updates, or compatibility adjustments with active libraries (`Atoolkit`, `WeebGfx`, and active prototypes).
